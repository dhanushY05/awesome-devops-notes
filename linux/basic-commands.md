# 🐧 Linux Basic Commands

Linux is a powerful operating system used in servers, DevOps, and cloud environments.

---

## 📍 1. pwd (Print Working Directory)

Shows the current directory you are in.

```bash
pwd
```

👉 Example output:
```
/home/user
```

---

## 📍 2. ls (List Files)

Lists files and directories.

```bash
ls
ls -l   # detailed view
ls -a   # hidden files
```

---

## 📍 3. cd (Change Directory)

Used to move between directories.

```bash
cd folder-name
cd ..
cd /
```

---

## 📍 4. mkdir (Make Directory)

Creates a new folder.

```bash
mkdir test
mkdir devops-project
```

---

## 📍 5. rm (Remove Files)

Deletes files or folders.

```bash
rm file.txt
rm -r folder-name   # remove folder
```

⚠️ Be careful: deleted files cannot be recovered easily.

---

## 📍 6. clear

Clears terminal screen.

```bash
clear
```

---

## 🎯 Summary

These are the most basic Linux commands used in:
- DevOps
- Cloud computing
- Server management
