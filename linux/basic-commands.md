# Linux Basic Commands

## pwd
Shows current directory.

```bash
pwd
```

---

## ls
Lists files and directories.

```bash
ls
```

---

## cd
Changes directory.

```bash
cd folder-name
```

---

## mkdir
Creates directory.

```bash
mkdir test
```

---

## rm
Deletes files.

```bash
rm file.txt
```

---

## clear
Clears terminal.

```bash
clear
```
