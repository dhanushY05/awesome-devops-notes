# 🌐 GitHub Workflow

GitHub workflow is the process of managing code using Git and GitHub.

---

## 📌 Basic Workflow

```txt
Write Code → Add → Commit → Push → GitHub
```

---

## 📌 Step 1: Clone Repository

```bash
git clone repository-url
```

Downloads repository from GitHub.

---

## 📌 Step 2: Make Changes

Edit files using:
- VS Code
- terminal
- text editor

---

## 📌 Step 3: Check Status

```bash
git status
```

---

## 📌 Step 4: Add Changes

```bash
git add .
```

Adds files to staging area.

---

## 📌 Step 5: Commit Changes

```bash
git commit -m "updated notes"
```

Saves changes locally.

---

## 📌 Step 6: Push to GitHub

```bash
git push
```

Uploads changes to GitHub repository.

---

## 📌 Pull Latest Changes

```bash
git pull
```

Gets latest updates from GitHub.

---

## 📌 Why GitHub Workflow is Important?

It helps:
- manage project history
- collaborate with teams
- track changes safely

---

## 🎯 Real DevOps Workflow

```txt
Developer → Git → GitHub → CI/CD → Server Deployment
```

---

## 🎯 Summary

GitHub workflow is used in:
- software development
- DevOps
- cloud projects
- team collaboration
