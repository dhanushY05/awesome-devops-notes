# 🔧 Git Basics

Git is a version control system used to track code changes and collaborate with developers.

---

## 📌 What is Git?

Git helps developers:
- track changes
- save code history
- work with teams
- manage different versions of projects

---

## 📌 Initialize Git Repository

```bash
git init
```

Creates a new Git repository.

---

## 📌 Check Repository Status

```bash
git status
```

Shows:
- modified files
- staged files
- untracked files

---

## 📌 Add Files

### Add single file

```bash
git add file-name
```

### Add all files

```bash
git add .
```

---

## 📌 Commit Changes

```bash
git commit -m "message"
```

Saves changes with a message.

Example:

```bash
git commit -m "Added Docker notes"
```

---

## 📌 View Commit History

```bash
git log
```

Shows all previous commits.

---

## 📌 Remove File from Git

```bash
git rm file.txt
```

---

## 📌 Clone Repository

```bash
git clone repository-url
```

Downloads repository from GitHub.

---

## 📌 Push Changes to GitHub

```bash
git push
```

Uploads local changes to GitHub.

---

## 📌 Pull Latest Changes

```bash
git pull
```

Downloads latest updates from GitHub.

---

## 🎯 Summary

Git is used for:
- version control
- team collaboration
- tracking project history

It is one of the most important tools in DevOps and software development.
